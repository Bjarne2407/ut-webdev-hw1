# PostIt

Homework 1 for Web Application Development (LTAT.05.004) at the University of
Tartu, fall 2026.

PostIt is a small made-up social feed. It's only HTML and CSS, so nothing gets
saved and the buttons just take you back to the feed. The point of the
homework is the markup and the styling.

Live site: <https://bjarne2407.github.io/ut-webdev-hw1/>

## Pages

- `index.html` is the feed. It has the nav bar, some posts (some with a photo,
  some text only) and a footer.
- `addPost.html` is the form for a new post, with a text area and a file
  picker.
- `login.html` is the login page. You can't submit it until both fields are
  filled in.

The layout uses Flexbox, so it should also work on a phone. You can check that
with the device toolbar in the browser dev tools.

## Running it locally

There's no build step. Just open `index.html` in a browser.
